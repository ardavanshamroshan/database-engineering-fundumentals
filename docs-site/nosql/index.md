# NoSQL

Key-value, document, and wide-column systems — chosen for scale patterns, flexible schemas, or specialized access models. Model for your query patterns first.

<ul class="engine-list">
  <li>
    <a href="./redis">Redis<span>In-memory structures — cache, sessions, queues, counters, streams.</span></a>
  </li>
  <li>
    <a href="./mongodb">MongoDB<span>Document store — flexible JSON/BSON documents, aggregation, indexes.</span></a>
  </li>
  <li>
    <a href="./cassandra">Cassandra<span>Wide-column, multi-DC CQL — partition-key modeling and tunable consistency.</span></a>
  </li>
  <li>
    <a href="./scylladb">ScyllaDB<span>Cassandra-compatible CQL with shard-per-core architecture.</span></a>
  </li>
</ul>
